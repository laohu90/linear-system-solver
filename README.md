# 二元一次方程组求解器 (Linear System Solver)

> 初中数学教学重点：二元一次方程组求解器，提供代入消元法与加减消元法详细步骤规范推导、精确分数运算、平面直角坐标系函数图象交点可视化、互动消元自测及经典中考真题库。

## 🌟 核心功能特色

### 1. 双消元法规范解题步骤
- **代入消元法 (Substitution Method)**：
  - 智能观察方程系数，优先选取含 $\pm 1$ 系数的未知数进行变形列出 ③ 式
  - 整体代入另一方程消元，展示去括号、移项、合并同类项、系数化为 1
  - 回代求值与联立解集规范书写 $\begin{cases} x = \dots \\ y = \dots \end{cases}$
- **加减消元法 (Elimination Method)**：
  - 自动寻找未知数系数的最小公倍数 (LCM)
  - 呈现两边同乘整数变形步骤（① $\times m_1$ 得 ③，② $\times m_2$ 得 ④）
  - 遵循“同号相减，异号相加”消元化简
- **全展模式 vs 逐步演练模式**：
  - 支持一键展开所有规范答题步骤，或切换为分步按键逐步揭示（非常适合投影教学与学生自学）。

### 2. 精确分数与自由整式输入
- **高精度分数内核 (`Fraction`)**：杜绝浮点数精度截断（如 0.333333），严格输出既约分数（如 $\frac{7}{3}$）。
- **多输入模式**：
  - 系数表格模式：支持填入整数、小数及分数（如 `2/3`, `-5/4`）
  - 自由表达式模式：支持输入带括号或分母的复杂方程，如 `2(x-1) = 3y + 4` 或 `x/2 + y/3 = 5`，自动去括号通分规范化。

### 3. 平面直角坐标系与函数图象交点
- 动态绘制两直线 $L_1$ 与 $L_2$ 及斜截式方程
- 高亮交点坐标 $P(x_0, y_0)$，支持缩放、平移拖拽与一键居中
- 直观展现**唯一解（两线相交）**、**无解（两线平行）**、**无数解（两线重合）**的几何本质。

### 4. 初一消元思维互动演练
- 引导学生自主判断“先消去哪一个未知数”、“使用哪种消元法更简便”
- 自主在草稿纸演算后填空核验，提供实时判定、考点点拨与庆祝彩带特效。

### 5. 经典题型与实际应用题库
- 内置基础题、中考常考题、符号陷阱题、去括号/去分母变式题、特殊解判定
- 经典实际应用题专题：《孙子算经》鸡兔同笼、车间螺栓螺母配套工程、轮船顺水逆水航行问题，包含完整题干、设元与列式。

### 6. 作业规范格式一键导出与打印
- 符合中国初中数学作业规范，支持一键复制纯文本或直接打印生成答题卡。
